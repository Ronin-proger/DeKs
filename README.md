# DeKs

Корпоративный аналитический сервис. Одно рабочее место, в котором сходятся показатели, база знаний и ежедневная операционная работа команды.

**DeKs** is an internal analytical workspace: operating dashboard, knowledge vault, semantic graph, and an assistant that answers from company notes.

## Зачем он нужен

В компаниях задачи, переписка, документы и заметки живут в разных местах. Решение принимается без контекста, который уже записан. DeKs собирает этот контур обратно: человек видит, что происходит, и может опереться на знания, а не искать их по чатам.

## Что умеет

- **Операционный дашборд.** Задачи, календарь, документы, общие ссылки, уведомления и поиск по рабочему пространству.
- **Коммуникации.** Общий и личный чат, вложения, непрочитанные.
- **База знаний.** Хранилище заметок, синхронизация, обзор покрытия и слабых мест.
- **Аналитика по знаниям.** Метрики хранилища, инсайты, обнаружение смысловых связей между заметками.
- **Граф.** Трёхмерная карта знаний: явные ссылки и семантические связи.
- **Ассистент.** Ответы по общему контексту и ответы, опирающиеся на заметки хранилища.

## Как это собрано

Клиент на React говорит с API на FastAPI. Пользователи, рабочее пространство и мессенджер лежат в SQLite. Заметки остаются markdown-хранилищем: сервис их синхронизирует, считает эмбеддинги, строит связи и отдаёт их в граф и в RAG.

Отдельный интеллектуальный контур не смешивается с обычными CRUD-операциями. Синхронизация, обогащение, поиск связей и ответы ассистента идут своим маршрутом `/api/intelligence`.

```text
React / Vite
    │
    ▼
FastAPI
    ├── workspace, messenger, profile, parser
    ├── SQLite
    └── intelligence
            ├── vault sync
            ├── embeddings and semantic links
            ├── metrics and insights
            └── RAG
                    │
                    ▼
              markdown vault + local model
```

## Запуск

Нужны Python 3.11+, Node.js 18+ и локальная модель, если нужен ассистент.

```bash
copy .env.example .env
start-all.bat
```

Интерфейс открывается на `http://localhost:5173`, API слушает порт `3001`.

Вручную:

```bash
cd server
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 3001 --reload
```

```bash
cd client
npm install
npm run dev
```

Либо `docker-compose up -d`.

Ключ хранилища и пути задаются только в `.env`. В репозиторий они не входят.
